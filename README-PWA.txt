ABU ADZKA Dashboard Custom - PWA

Cara menjadikan aplikasi ini bisa dipakai di Android dan iPhone:

1. Upload seluruh isi folder ini ke hosting HTTPS.
   Rekomendasi mudah: Netlify, Vercel, GitHub Pages, atau hosting domain sendiri.

2. Buka URL website dari browser HP.

3. Android:
   Buka Chrome, pilih menu titik tiga, lalu pilih "Add to Home screen" atau "Install app".

4. iPhone:
   Buka Safari, pilih tombol Share, lalu pilih "Add to Home Screen".

Catatan:
- PWA tidak bisa aktif penuh jika hanya dibuka dari file lokal atau link WhatsApp content://.
- Service worker/offline cache aktif setelah aplikasi dibuka dari HTTPS.
- Data demo dan input tersimpan di localStorage browser/device masing-masing.
